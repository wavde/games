# Roadmap

Proposals for growing the collection. Nothing here is committed scope until picked. Exploratory non-game puzzles/simulations belong in the separate curiosity-lab repo; this repo stays a games collection.

## Current inventory

- **43 games**, each a self-contained folder with `index.html` + `game.js`, linked from the hub (`index.html`).
  - Classics: tic-tac-toe, 2048, minesweeper, memory, chess, connect-four, lights-out, code-breaker, slide-15, reversi, dots-and-boxes, gomoku, checkers, mancala, battleships, sokoban, snake, breakout, klondike, freecell, morris, hex, spider.
  - Logic puzzles: mini-sudoku, tango, queens, zip, patches, nonogram, hashi, akari, slitherlink, star-battle, kakuro, hitori, nurikabe, calcudoku, skyscrapers, futoshiki, tents, jigsaw-sudoku, norinori, lits.
- **Shared layer** (all 43 games load `shared.css`, `soft.css`, `manpage.css`, `manpage.js`):
  - `gamekit.js` (`window.Gamekit`): mulberry32 PRNG, `dailySeed`, `storage(prefix)`, `wireDifficultyChips`, `fmtTime`, `onLongPress`, `shuffle`, `gridKeys` (keyboard play), `puzzleClock` (timer + best time for the 11 timed puzzles), `markDailySolved`/`dailySolved` (today's solved dailies, shown on the hub), and for the digit puzzles (calcudoku, kakuro, skyscrapers, futoshiki, jigsaw-sudoku) `domainSolver` (bitmask propagate → probe → search), `latinSquare`, `numberPad`. Loaded by all 43 games and the hub.
  - Daily-seed + easy/medium/hard chip pattern: lights-out, code-breaker, slide-15, mini-sudoku, tango, queens, zip, patches, nonogram, hashi, akari, slitherlink, star-battle, kakuro, hitori, nurikabe, calcudoku, skyscrapers, futoshiki, tents, jigsaw-sudoku, norinori, lits, sokoban. klondike's daily deal uses draw 1 / draw 3 chips; freecell has one daily deal; spider's chips pick 1 / 2 / 4 suits. connect-four, reversi, dots-and-boxes, gomoku, checkers, mancala, battleships, morris, and hex use chips for AI level.
  - Help: a `<template id="man-<game>">` + `.man-trigger` button per game.
  - Game pages (`body.g-<name>`) always use soft.css's warm-dark palette; the dark/light toggle only affects the hub.
- **No build, no runtime dependencies.** CI checks (below) install their tools only in CI.

## Proposed improvements

1. **Cheap syntax check** — run `node --check` over all JS before committing (see commands below). No tooling added; a portable Node works fine.
2. **Hub freshness** — keep the `new` badge on the three most recent games only (currently spider, norinori, lits).
3. **zip uniqueness** ✅ — every board is unique. A pruned path solver (degree, connectivity, colour-parity, and forced-move checks) lists alternative paths; the generator greedily adds whichever number or wall rules out the most, within per-tier caps. ~5 ms easy, ~20 ms medium, ~170 ms hard (worst ~0.6 s); 120/120 boards confirmed unique by an independent solver.

4. **Keyboard play** ✅ — every game is playable by keyboard: shared `Gamekit.gridKeys` gives each board one Tab stop, arrow-key movement (by on-screen position, so sparse boards like hashi work; dots-and-boxes walks its line lattice), Enter/Space to play, and F/X for flag/mark. Board buttons use `aria-disabled` instead of `disabled` so focus survives AI turns.
5. **CI checks** ✅ — `.github/workflows/checks.yml` runs `node --check`, ESLint, html-validate, a headless-Chrome pass (page errors, manpage auto-open, axe-core), and logic checks on every push and PR. Tools install only in CI; the site stays dependency-free.
6. **Logic checks in CI** ✅ — `.github/checks/logic.mjs` loads each game in headless Chrome with a test-only hook that exposes its internals, then checks (fixed seeds): every board of the 18 generated puzzles and all 900 banked norinori/lits boards has exactly one solution, graded puzzles still meet their grade, sokoban par matches an independent forward push search, snake's rules hold (walls, wrap, growth, no reversal, tail-chasing, invariants over random play), breakout's physics hold (ball stays in the arena, never flatter than 60° from vertical, exact brick and score counts per level, a still paddle loses), klondike's solver lines replay as legal moves to a win in both draw modes, freecell deals match the published layouts and random play conserves all 52 cards within the move-size limit, morris and hex rules hold (mills, taking, flying; exactly one winner on full boards) and their AIs only play legal moves, spider deals hold the right cards for 1 / 2 / 4 suits and random play conserves all 104 cards and clears finished runs, checkers matches perft 1–7, mancala matches an independent Kalah model, and the checkers/mancala/battleships AIs only play legal moves. It caught that queens boards were almost never unique; queens now repairs regions until one answer remains (150/150 confirmed by CP-SAT).

## Code-quality audit (latest)

- **ESLint** (`recommended` + `eqeqeq`, `no-var`, `prefer-const`, `no-unused-vars`, `no-implicit-globals`, `no-use-before-define`): 0 errors, 0 warnings across all JS. Every script is an IIFE in strict mode; no globals leak besides `Gamekit` and `Manpage`.
- **html-validate** (`recommended`): 0 messages on all 44 pages (hub + 43 games).
- **axe-core** (WCAG 2.0/2.1 A+AA + best practices): 0 violations on every page freshly loaded, after random play, with the manpage open, and on the hub in light mode.
- No `console`/`debugger`/TODO leftovers; `innerHTML` only ever receives fixed strings and numbers (no user input).
